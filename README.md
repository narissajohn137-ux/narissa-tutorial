ITE 1100 – Git and GitHub Tutorial
Purpose of the Repository
This repository was created for my ITE 1100 tutorial assignment. Its purpose is to demonstrate my understanding of Git and Git hub 
by creating and managing branches, adding files and recording changes through commits. Lastly this repository was used to practice 
collaboration through GitHub by creating a pull request to propose changes, requesting a review, and merging the approved changes 
into the main branch, allowing them to be stored and accessed online.

Steps Followed
1. Installed Git and created a GitHub account.
2. Created a local repository named (narissa-tutorial)
3. Connected the local repository to a public GitHub repository.
4. Invited a classmate to collaborate on the repository.
5. Created a branch named (tutorial-branch)
6. Created two files: (tutorial.py) and (tutorial.txt)
7. Staged and committed the files using Git Bash.
8. Created and pushed the (master) branch to GitHub.
9. Updated (tutorial.txt) and committed the changes on (tutorial-branch)
10. Pushed (tutorial-branch) to GitHub.
11. Created a pull request to merge (tutorial-branch) into (master)
12. Requested a review from my classmate.
13. My classmate reviewed and merged the pull request.
